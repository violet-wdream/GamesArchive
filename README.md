## Introduction

GamesArchive is an archival repository for **Spine / Live2D model data** and
related materials from various games.

The repository may include:
- Spine / Live2D model files
- Brief unpacking or extraction notes for specific games
- Publicly available links to archived data of discontinued games (if any)

This project is intended for **research, learning, and preservation purposes**.
